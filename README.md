# linkedin-skills

A collection of [Claude](https://claude.com/claude-code) skills for working on LinkedIn.

## Install

In Claude Code:

```
/plugin marketplace add smedavarapu1/linkedin-skills
/plugin install linkedin-skills@linkedin-skills
```

## Adding a skill

1. Copy `templates/SKILL.template.md` to `skills/<skill-name>/SKILL.md`.
2. Fill in the `name` and `description` frontmatter; the description is what Claude uses to decide when to run it.
3. Put any supporting files (rubrics, JSON data, scripts) in the same folder.
4. Add a row to the table above.
